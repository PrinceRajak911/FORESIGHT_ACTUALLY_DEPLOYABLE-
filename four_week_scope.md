# Four-Week Internship Scope

This repository is organised around the project's stated four-week engagement structure.

## Week 1 — Data Foundation
- ingestion and schema checks
- duplicate/missing-value handling
- category standardisation
- analysis-ready dataset
- data-quality report

## Week 2 — EDA & Baseline
- weekly demand construction
- demand distribution analysis
- seasonality/promotion analysis
- seasonal-naive baseline
- WAPE and bias

## Week 3 — Modelling & Risk
- lag/rolling/calendar features
- Random Forest forecasting model
- rolling-origin backtest
- model-vs-baseline selection
- stockout/overstock scoring
- decisioning actions and ₹ impact

## Week 4 — Productisation
- six-week forecast artifact
- Streamlit planning dashboard
- FastAPI scoring service
- Docker configuration
- documentation and final handoff

This is a scope plan, not a claim about historical work that did not happen.
