# Project FORESIGHT Synthetic Dataset

Deterministic synthetic client extracts for demand forecasting and inventory
risk scoring.

- 150 SKUs
- 2 years of daily sales history
- Product/category heterogeneity
- Weekly/calendar seasonality
- Promotions and holidays
- Weekly inventory snapshots
- Deliberate missing values, duplicate sales rows and inconsistent labels

The project pipeline must calculate all forecast, risk and business-impact
results; no model results are fabricated in the dataset.
